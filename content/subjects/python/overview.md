Python is a general-purpose programming language designed to be easy to read and quick to write. Its clean syntax, large standard library, and enormous ecosystem of packages have made it the most common first language in universities and one of the main languages of data science, machine learning, automation, and web back ends. LuminaLearn's own backend and AI tutor are written in Python.

This subject takes you from your first variable to writing well-structured, tested programs. It begins with Python's object model: what a variable really is, how the built-in types behave, and why mutability decides whether a change is shared. It then covers control flow, functions and scope, and the features that make Python expressive: iterators, generators, closures, and decorators. The middle of the subject is about data: lists, dictionaries, tuples, sets, comprehensions, and string handling. The final modules cover object-oriented programming, exceptions, files, modules and packages, the standard library, testing and debugging, and the idioms used in algorithmic code.

Every lesson includes runnable examples with their exact output, so you can type them in and confirm that Python behaves as described.

## What you will learn
- Explain Python's model of names bound to objects and predict the behaviour of mutable and immutable types
- Convert between types and use Python's arithmetic, comparison, and boolean operators correctly
- Control program flow with conditionals and loops, including break, continue, and the loop else clause
- Write functions with flexible parameters, trace name lookup with the LEGB rule, and use closures and decorators
- Process data lazily with iterators and generators
- Choose between lists, dictionaries, tuples, and sets, and write clear comprehensions
- Format and manipulate text with f-strings and string methods
- Design classes with inheritance and polymorphism, and handle errors with exceptions
- Read and write files safely with context managers, and organise code into modules and packages
- Use the standard library, write unit tests, and debug programs systematically

## Glossary
- **Object**: a value in memory with an identity, a type, and a value; everything in Python is an object
- **Variable**: a name bound to an object; assignment binds a name and never copies the object
- **Mutable**: describes an object that can be changed in place, such as a list or dictionary
- **Immutable**: describes an object that cannot be changed once created, such as an int, str, or tuple
- **Function**: a named, reusable block of code that takes arguments and returns a value
- **Scope**: the region of code where a name is visible, resolved by the LEGB rule
- **Iterable**: any object that can be looped over, such as a list, string, or file
- **Generator**: a function that uses yield to produce values one at a time, on demand
- **Comprehension**: a compact expression that builds a list, set, or dictionary from an iterable
- **Class**: a blueprint for objects that bundles data (attributes) with behaviour (methods)
- **Exception**: an object that signals an error and interrupts normal flow until it is handled
- **Module**: a single Python file whose definitions can be imported by other code
- **Package**: a directory of modules that can be imported as a unit
- **Context manager**: an object used in a with statement that sets up and reliably cleans up a resource
