Java is an object-oriented language built around the idea of "write once, run anywhere". Java source code compiles to bytecode, which runs on the Java Virtual Machine (JVM) on any operating system. Automatic garbage collection, a strong static type system, and a vast standard library have made Java a mainstay of enterprise back ends, Android apps, big-data systems, and university programming courses.

This subject begins with the JVM: how bytecode is loaded, verified, and executed, and how memory is split between the stack and the garbage-collected heap. It then covers Java's syntax, types, control flow, strings, arrays, and wrapper classes. The core modules teach object-oriented programming in depth: classes and object allocation, inheritance and `super`, run-time polymorphism and dynamic binding, abstract classes, and interfaces with default methods. Later modules cover checked and unchecked exceptions, the Collections Framework, lambdas and the Streams API, generics with wildcard bounds, file I/O with `java.nio`, and multithreading with synchronization and the concurrency utilities.

Examples are complete programs you can compile and run, so you can see each concept working rather than read about it in the abstract.

## What you will learn
- Explain how the JVM loads and runs bytecode and how garbage collection manages memory
- Write Java programs using its types, control flow, strings, arrays, and wrapper classes
- Define classes and objects, and explain how objects are allocated and referenced
- Use inheritance, method overriding, and dynamic binding to build polymorphic designs
- Choose between abstract classes and interfaces, including default methods
- Handle errors with checked and runtime exceptions
- Use the Collections Framework, lambdas, and the Streams API to process data
- Write type-safe generic classes and methods with bounded wildcards
- Read and write files with java.nio and write correct multithreaded code

## Prerequisites
- Basic programming experience in any language, such as variables, loops, and functions
- No prior knowledge of object-oriented programming is required
- A Java Development Kit (JDK) 17 or later

## Glossary
- **JVM**: the Java Virtual Machine, which executes compiled Java bytecode
- **Bytecode**: the platform-independent instruction format produced by the Java compiler
- **Garbage collection**: automatic reclamation of heap objects that are no longer reachable
- **Class**: a blueprint defining the fields and methods of a type of object
- **Object**: an instance of a class, allocated on the heap
- **Inheritance**: defining a class as an extension of another, reusing and refining its behaviour
- **Polymorphism**: one interface, many implementations; the method that runs depends on the object's actual class
- **Interface**: a contract of methods that implementing classes must provide
- **Checked exception**: an exception the compiler requires you to catch or declare
- **Generics**: type parameters that let classes and methods work with many types safely
- **Collection**: a framework type such as List, Set, or Map that holds groups of objects
- **Stream**: a sequence of elements supporting functional-style operations such as map and filter
- **Thread**: an independent path of execution within a program
