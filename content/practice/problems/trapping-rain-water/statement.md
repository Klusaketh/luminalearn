`heights[i]` is the height of a bar of width 1. After it rains, water collects between the bars. Return how many units of water are trapped.

### Examples

- `heights = [0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1]` → `6`
- `heights = [4, 2, 0, 3, 2, 5]` → `9`
- `heights = [1, 2, 3]` → `0`

### Constraints

- `0 <= len(heights) <= 2 * 10^4`, `0 <= heights[i] <= 10^5`

**Challenge:** $O(n)$ time and $O(1)$ extra space.
