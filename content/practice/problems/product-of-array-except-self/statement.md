Return a list `answer` where `answer[i]` is the product of every element of `nums` **except** `nums[i]`. Do it **without division**.

### Examples

- `nums = [1, 2, 3, 4]` → `[24, 12, 8, 6]`
- `nums = [-1, 1, 0, -3, 3]` → `[0, 0, 9, 0, 0]`

### Constraints

- `2 <= len(nums) <= 10^5`
- The answer fits in a 32-bit integer.

**Challenge:** $O(n)$ time, and no extra list besides the answer.
