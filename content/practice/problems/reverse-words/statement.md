Given a sentence `s`, return the words in reverse order, separated by **single spaces**.

The input may have leading or trailing spaces, or several spaces between words. The result must have none of these.

### Examples

| `s` | Result |
| :--- | :--- |
| `"the sky is blue"` | `"blue is sky the"` |
| `"  hello world  "` | `"world hello"` |
| `"a good   example"` | `"example good a"` |

### Constraints

- `0 <= len(s) <= 10^4`
