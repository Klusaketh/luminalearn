Return the `k` values that appear most often in `nums`, **most frequent first**. When two values appear equally often, put the **smaller value first**.

### Examples

- `nums = [1, 1, 1, 2, 2, 3]`, `k = 2` → `[1, 2]`
- `nums = [4, 4, 6, 6, 5]`, `k = 2` → `[4, 6]`
- `nums = [7]`, `k = 1` → `[7]`

### Constraints

- `1 <= k <=` the number of distinct values in `nums`.
