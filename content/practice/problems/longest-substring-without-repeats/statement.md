Return the length of the longest **substring** of `s` (a contiguous run of characters) in which no character appears twice.

### Examples

| `s` | Result | Longest substring |
| :--- | :--- | :--- |
| `"abcabcbb"` | `3` | `"abc"` |
| `"bbbbb"` | `1` | `"b"` |
| `"pwwkew"` | `3` | `"wke"` (`"pwke"` is not contiguous) |

### Constraints

- `0 <= len(s) <= 5 * 10^4`
