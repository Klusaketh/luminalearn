Return the length of the longest **substring** of `s` (a contiguous run of characters) in which no character appears twice.

### Examples

- `s = "abcabcbb"` → `3` (longest substring: `"abc"`)
- `s = "bbbbb"` → `1` (longest substring: `"b"`)
- `s = "pwwkew"` → `3` (longest substring: `"wke"` (`"pwke"` is not contiguous))

### Constraints

- `0 <= len(s) <= 5 * 10^4`
