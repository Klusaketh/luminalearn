`nums` is sorted in increasing order and has no duplicates. Return the index of `target` in `nums`, or `-1` if it is not there.

Your solution must run in $O(\log n)$ time, so it cannot look at every element.

### Examples

| `nums` | `target` | Result |
| :--- | :--- | :--- |
| `[-1, 0, 3, 5, 9, 12]` | `9` | `4` |
| `[-1, 0, 3, 5, 9, 12]` | `2` | `-1` |
| `[]` | `5` | `-1` |

### Constraints

- `0 <= len(nums) <= 10^4`
