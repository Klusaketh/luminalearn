Move every `0` in `nums` to the end while keeping the **relative order** of the non-zero values. Rearrange the list in place and **return it**.

### Examples

- `nums = [0, 1, 0, 3, 12]` → `[1, 3, 12, 0, 0]`
- `nums = [0]` → `[0]`
- `nums = [4, 2, 0]` → `[4, 2, 0]`

### Constraints

- `1 <= len(nums) <= 10^4`

**Challenge:** use $O(1)$ extra space: no second list.
