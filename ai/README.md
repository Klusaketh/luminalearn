# LuminaLearn AI — Socratic Agent & AI Framework

## Overview
The `ai/` module houses the Socratic AI Agent framework, versioned prompt templates, Retrieval-Augmented Generation (RAG) vector pipelines, and non-deterministic LLM evaluation suites.

## Directory Structure
- `agents/`: Specialized Socratic dialogue agents, cognitive load adjusters, and resource generators.
- `prompts/`: Versioned prompt templates enforcing strict zero-direct-answer guardrails.
- `rag/`: Vector embedding pipelines and retriever connectors for Qdrant.
- `evaluation/`: LLM-as-a-judge regression testing harnesses.
